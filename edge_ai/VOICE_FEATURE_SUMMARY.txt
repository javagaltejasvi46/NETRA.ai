WHAT WAS BUILT
================================================================================

1. ✅ Welcome Message on Startup
   - System says: "Hello. Welcome to NETRA dot A I. Battlefield copilot ready."
   - Opens 5-second listening window after welcome

2. ✅ Voice Input After Every Decision
   - After each tactical decision is spoken
   - 5-second listening window opens automatically
   - User can ask questions about the situation

3. ✅ Audio Processing Pipeline
   - Records audio from microphone
   - Applies noise reduction (denoising)
   - Converts speech to text using Whisper AI
   - Processes user question

4. ✅ Context-Aware Responses
   - LLM remembers last 5 telemetry updates
   - LLM remembers last 5 tactical decisions
   - LLM remembers last 10 conversation exchanges
   - Generates contextual answers

5. ✅ Brief Responses
   - All responses limited to 20 words maximum
   - Direct and tactical communication style

6. ✅ Voice Output
   - Converts response to speech using Piper TTS
   - Plays audio through speakers
   - Error handling prevents system crashes

HOW TO USE
================================================================================

STEP 1: Install Voice Feature
  cd edge_ai
  chmod +x setup_voice.sh
  ./setup_voice.sh

STEP 2: Test Installation
  python3 test_voice_input.py

STEP 3: Start System
  ./START_HERE.sh

STEP 4: Interact
  - System will greet you on startup
  - Send telemetry via MQTT
  - System analyzes and speaks decision
  - Ask questions during 5-second window
  - System responds with context-aware answers

================================================================================
CONFIGURATION
================================================================================

Edit config.py to customize:

  VOICE_INPUT_ENABLED = True          # Enable/disable feature
  WHISPER_MODEL = "base"              # tiny, base, small, medium, large
  LISTENING_DURATION = 5              # Seconds to listen
  ENABLE_WELCOME_MESSAGE = True       # Welcome on startup

Recommended for Raspberry Pi 4:
  WHISPER_MODEL = "base"              # Good balance
  LISTENING_DURATION = 5              # Standard window

Recommended for Raspberry Pi 3:
  WHISPER_MODEL = "tiny"              # Faster processing
  LISTENING_DURATION = 3              # Shorter window

================================================================================
TECHNICAL DETAILS
================================================================================

Speech Recognition:
  - Engine: OpenAI Whisper
  - Noise Reduction: noisereduce library
  - Audio Format: 16kHz, 16-bit, mono WAV
  - Recording: arecord (ALSA)

Context Memory:
  - Telemetry: Last 5 updates
  - Decisions: Last 5 tactical decisions
  - Conversations: Last 10 exchanges
  - Storage: In-memory (not persisted)

Response Generation:
  - Uses same LLM as tactical decisions
  - Context-aware prompts
  - 20-word limit enforced
  - Tactical communication style

Voice Output:
  - Engine: Piper TTS
  - Voice: en_US-lessac-medium
  - Format: WAV audio
  - Playback: pygame/aplay/winsound

================================================================================
TROUBLESHOOTING
================================================================================

No Audio Input:
  - Check: arecord -l
  - Test: arecord -D plughw:1,0 -d 5 test.wav
  - Adjust: alsamixer

Poor Transcription:
  - Use larger model: WHISPER_MODEL = "small"
  - Reduce noise in environment
  - Use better microphone

Slow Performance:
  - Use smaller model: WHISPER_MODEL = "tiny"
  - Reduce duration: LISTENING_DURATION = 3
  - Disable noise reduction

Voice Not Triggering:
  - Check: VOICE_INPUT_ENABLED = True
  - View logs: tail -f logs/edge_ai_*.log
