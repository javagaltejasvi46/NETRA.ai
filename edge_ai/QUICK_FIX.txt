================================================================================
QUICK FIX: "externally-managed-environment" Error
================================================================================

THE PROBLEM:
You can't install Python packages with pip3 because Raspberry Pi OS protects
system packages.

FASTEST SOLUTION (Choose One):
================================================================================

Option 1: Virtual Environment (RECOMMENDED - Safe)
---------------------------------------------------
cd edge_ai
chmod +x install_llm_venv.sh
./install_llm_venv.sh

# Then always run with:
source venv/bin/activate
python3 main.py


Option 2: System-Wide (SIMPLER - But risky)
--------------------------------------------
cd edge_ai
chmod +x install_llm_system.sh
./install_llm_system.sh

# Then run normally:
python3 main.py


Option 3: One-Line Manual Install (System-Wide)
------------------------------------------------
sudo apt-get install -y build-essential cmake libopenblas-dev && \
CMAKE_ARGS="-DLLAMA_BLAS=ON -DLLAMA_BLAS_VENDOR=OpenBLAS" \
pip3 install llama-cpp-python --no-cache-dir --break-system-packages


Option 4: One-Line Manual Install (Virtual Env)
------------------------------------------------
python3 -m venv venv && \
source venv/bin/activate && \
pip install --upgrade pip && \
sudo apt-get install -y build-essential cmake libopenblas-dev && \
CMAKE_ARGS="-DLLAMA_BLAS=ON -DLLAMA_BLAS_VENDOR=OpenBLAS" \
pip install llama-cpp-python --no-cache-dir

================================================================================

AFTER INSTALLATION:
-------------------
1. Download model (if not already done):
   mkdir -p models
   wget https://huggingface.co/TheBloke/TinyLlama-1.1B-Chat-v1.0-GGUF/resolve/main/tinyllama-1.1b-chat-v1.0.Q4_K_M.gguf -O models/tinyllama.gguf

2. Test installation:
   ./check_llm_and_test.sh

3. Run the copilot:
   python3 main.py

================================================================================

WHICH OPTION SHOULD I CHOOSE?
------------------------------
- Development/Testing: Use Option 1 (Virtual Environment)
- Production/Service: Use Option 2 (System-Wide)
- Quick Test: Use Option 3 (One-liner system-wide)

================================================================================

TROUBLESHOOTING:
----------------
Q: "No module named 'llama_cpp'" after venv install
A: Did you activate? Run: source venv/bin/activate

Q: Build takes forever
A: Normal on Raspberry Pi. Takes 10-15 minutes. Be patient!

Q: Out of disk space
A: Run: sudo apt-get clean && sudo apt-get autoremove

Q: Still getting errors
A: Read INSTALL_GUIDE.md for detailed instructions
